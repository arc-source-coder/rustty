Windows Terminal-style custom titlebar with integrated tab strip.

Tab component:
- label (title from session metadata.title, fallback to spawn_config.shell_program)
- close button (X)
- active indicator (blended highlight - similar to Windows Terminal / Chrome).
- New tab button (+).
 
Tab actions:
- click to switch
- middle-click to close
- Ctrl+T new tab
- Ctrl+W close active tab
- Ctrl+Tab / Ctrl+Shift+Tab - next/prev tab
- Ctrl+1-9 jump to tab by index.
 
Focus transfer: on tab switch, ensure active terminal session receives keyboard focus.

Titlebar: drag to move window, double-click to maximize/restore (already works as GPUI handles it, however, it should be integrated with the tabs).

Tab reorder by drag: Vec::remove + Vec::insert on tabs vec (stable TabId).
