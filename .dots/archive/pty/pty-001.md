Wrap portable-pty with typed PtyCommand (Write/Resize/Close) and PtyEvent (Output/Exited/Error) enums. Bounded channels: PTY_EVENT_CHANNEL_CAPACITY=64, PTY_COMMAND_CHANNEL_CAPACITY=64. Spawn PowerShell (powershell.exe) with inherited parent env (override TERM=xterm-256color, COLORTERM=truecolor), blocking read on background thread, write/resize on command receipt. Resize coalescing (last-wins). Shutdown ordering: signal stop → unblock blocking read → drain queued events → emit Exited → join threads. Integration tests: spawn/write/read/resize/exit. ConPTY edge cases to test: UTF-16 chunking, resize during output, fast close, process exit detection. Refs: docs/architecture/04-pty-threading.md (full design), docs/architecture/02-data-model.md § PTY Channel Bounds + § PTY Model.
