Workspace struct: tabs: Vec<TabId>, tab_entries: HashMap<TabId, TabEntry>, active_tab: TabId. TabEntry { content: TabContent }. TabContent::Terminal(Entity<TerminalSession>). TabId/SessionId: newtypes over u64, generated via module-level AtomicU64 counter (monotonic, never from Vec index or GPUI EntityId). Single-tab bootstrap: open GPUI window → create Workspace → spawn TerminalSession (with SpawnConfig defaults: powershell.exe, 80x24, xterm-256color) → wrap in TabEntry → set as active_tab → render. Window close when tabs.is_empty(). RenderConfig as shared Model<RenderConfig> (defaults for v0: no config file). Wire terminal renderer into workspace render tree. Refs: docs/architecture/02-data-model.md § App-Level Models + § Stable Identity + § RenderConfig Sharing, docs/architecture/01-system-overview.md § Ownership Boundaries.
