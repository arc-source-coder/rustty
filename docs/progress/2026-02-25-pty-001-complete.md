## What was built

Initial PTY crate implementation with typed PtyCommand (Write/Resize/Close) and PtyEvent (Output/Exited/Error) enums. The PTY backend is a port of Alacritty's PTY backend from the `alacritty_terminal` crate (Used by Zed and Alacritty) modified to use the PtyCommand and PtyEvent Enums instead of the EventedReadWrite trait.

The Windows Terminal approach of closing HPCON to allow graceful shutdown has been ported with the same timeout (1s). If timeout elapses, the process is forcefully terminated. This prevents hanging on close due to a PTY deadlock.

## Key decisions

- Use the Alacritty PTY backend instead of portable-pty, which is buggy on Windows. The Alacritty backend is used by the Alacritty Terminal app and in Zed's built-in terminal, and is proven to work on Windows..
